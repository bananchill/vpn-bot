# TASK-002: Скрытые команды владельца для управления администраторами

**Статус:** Ожидает апрува
**Приоритет:** Высокий
**Дата:** 2026-02-28

## Описание
Необходимо добавить скрытые команды, доступные только владельцу бота (OWNER_ID из переменной окружения), для управления администраторами: назначение, снятие и просмотр списка. Команды не регистрируются в BotCommands и не отображаются в меню, что делает их невидимыми для обычных пользователей.

## Что будет сделано
1. Добавить поле `OWNER_ID: int` в `Settings` класс в `bot/config.py`
2. Добавить `OWNER_ID` в `.env.example`
3. Создать новый файл `bot/handlers/owner.py` с роутером и тремя обработчиками:
   - `/setadmin <telegram_id>` — назначить пользователя администратором
   - `/rmadmin <telegram_id>` — снять права администратора
   - `/admins` — показать список текущих администраторов
4. В каждом обработчике проверить, что `message.from_user.id == settings.OWNER_ID`, иначе игнорировать сообщение (без ответа)
5. Подключить `owner_router` в `bot/__main__.py` первым в списке (до остальных роутеров)

## Какие файлы будут затронуты
- `bot/config.py` — изменение, добавление поля `OWNER_ID: int` в класс `Settings`
- `bot/handlers/owner.py` — новый файл, обработчики трёх скрытых команд
- `bot/__main__.py` — изменение, импорт и подключение `owner_router`
- `.env.example` — изменение, добавление строки `OWNER_ID=your-telegram-id`

## Пользовательский сценарий

Назначение администратора (от лица владельца):
```
Владелец: /setadmin 123456789
Бот: Пользователь 123456789 назначен администратором.

Владелец: /setadmin 123456789  (уже является админом)
Бот: Пользователь 123456789 уже является администратором.

Владелец: /setadmin  (без аргумента)
Бот: Использование: /setadmin <telegram_id>

Владелец: /setadmin abc  (невалидный ID)
Бот: Ошибка: telegram_id должен быть числом.
```

Снятие прав администратора:
```
Владелец: /rmadmin 123456789
Бот: Права администратора сняты с пользователя 123456789.

Владелец: /rmadmin 123456789  (не является админом или не найден)
Бот: Пользователь 123456789 не найден или не является администратором.
```

Просмотр списка администраторов:
```
Владелец: /admins
Бот: Текущие администраторы:
     - @username1 (ID: 111111111)
     - @username2 (ID: 222222222)

Владелец: /admins  (нет ни одного)
Бот: Администраторов нет.
```

Обращение не от владельца:
```
Обычный пользователь: /setadmin 999
Бот: (нет ответа — команда игнорируется)
```

## Технические решения
- Фильтрация по OWNER_ID реализуется через фильтр на уровне регистрации команды в роутере (aiogram filter). При несовпадении aiogram просто не вызывает обработчик — пользователь не получает никакого ответа.
- `owner_router` подключается первым в `dp.include_router(...)`, чтобы он имел наивысший приоритет и не конфликтовал с другими роутерами.
- `UserRepository.set_admin()` уже существует и умеет устанавливать `is_admin=True/False` — переиспользуем без изменений.
- `UserRepository.list_admins()` уже существует — переиспользуем без изменений.
- Если пользователь не найден в БД при `/setadmin` или `/rmadmin`, возвращать ошибку "Пользователь не найден." (пользователь должен хоть раз написать боту).
- `db_session` инжектируется через существующий `AuthMiddleware` — хендлеры используют его стандартным образом.
- Команды НЕ добавляются через `bot.set_my_commands()` — это и есть механизм скрытости.

## Критерии приёмки
- [ ] `/setadmin <id>` от OWNER_ID назначает пользователя администратором, поле `is_admin` в БД становится `True`
- [ ] `/rmadmin <id>` от OWNER_ID снимает права администратора, поле `is_admin` в БД становится `False`
- [ ] `/admins` от OWNER_ID возвращает список всех администраторов из БД
- [ ] Все три команды не реагируют на запросы от любого пользователя, кроме OWNER_ID (нет ответа)
- [ ] Некорректный аргумент (не число, отсутствие аргумента) возвращает пояснительное сообщение
- [ ] `OWNER_ID` добавлен в `Settings` и в `.env.example`
- [ ] `owner_router` подключён в `__main__.py` первым
- [ ] Команды не зарегистрированы в BotCommands и не видны в меню

## Вне скоупа
- Управление правами через inline-кнопки или меню
- Уведомление назначенного пользователя о получении или снятии прав администратора
- Логирование действий владельца
- Назначение владельцем самого себя администратором
